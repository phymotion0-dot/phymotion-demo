# Video Demos (Anonymous Supplementary Material)

Side-by-side generated human-motion comparisons for 16 prompts across 5 models
(**Ours** vs four baselines). Open `index.html` (e.g., via GitHub Pages) to view the gallery,
or browse `static/videos/<model>/<idx>.mp4` directly.

All videos are anonymized (metadata stripped). This repository contains no author or
institution information.
